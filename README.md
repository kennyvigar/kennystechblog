## How it was built

This site carries its own paper trail.

- **[specs/](specs/)** one file per feature: what it does, how it works and which
  alternatives lost.
- **[AGENT.md](AGENT.md)** the guardrails any agent works under here.

There is also a `revert to pre-ai design` button on the site. It swaps the whole
thing back to the original, bugs included, so the before picture is something you
can look at rather than something you have to take on trust.
